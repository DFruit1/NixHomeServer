- `audiobookshelf.svg`: https://raw.githubusercontent.com/advplyr/audiobookshelf/master/client/static/icon.svg
- `jellyfin.svg`: https://raw.githubusercontent.com/jellyfin/jellyfin-ux/master/branding/SVG/icon-transparent.svg
- `kavita.svg`: https://raw.githubusercontent.com/Kareadita/Kavita/develop/UI/Web/src/assets/images/logo.svg
- `calibre-web.svg`: https://raw.githubusercontent.com/janeczku/calibre-web/master/cps/static/icon.svg
- `vaultwarden.svg`: https://raw.githubusercontent.com/dani-garcia/vaultwarden/main/resources/vaultwarden-icon.svg
- `mail-archive-ui.svg`: repository-local Mail Archive mark: a folded teal envelope holding an archived letter (redesigned with owner authorization, 2026-11-05).
- `kanidm.svg`: https://raw.githubusercontent.com/kanidm/kanidm/master/artwork/logo-square.svg (Kanidm artwork by Jesse Irwin, used unmodified under CC-BY-NC-ND for identity-provider attribution on the Keys & Secrets page)
- `forgejo.svg`: unmodified [Forgejo v15.0.3 logo](https://codeberg.org/forgejo/forgejo/raw/tag/v15.0.3/assets/logo.svg), replacing the homemade attribution mark with owner authorization, 2026-11-05. Artwork by Caesar Schinas, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); see the [upstream branding guide](https://codeberg.org/forgejo/governance/src/branch/main/branding#logo).
- `archives.svg`: repository-local Web Archives mark: layered browser captures in a blue archive tray.
- `search.svg`: repository-local Search mark: a teal lens over indexed text with an amber focus point.
- `bonsai.svg`: repository-local Bonsai mark: a jade canopy, branching trunk and terracotta pot.
- `ai-tools.svg`: repository-local AI Tools mark: interlocking violet connectors with an amber joint.
- `qwen-27b.svg`: repository-local Local AI mark: three interwoven amber lobes around a hexagonal core.
- `media-manager.svg`: repository-local Media Manager mark: layered media sheets in a blue folder with a play cutout.
- `chaptarr.svg`: repository-local Book Downloads mark: an open blue book with an amber bookmark.

The custom marks above were redesigned with owner authorization on 2026-11-05. They use transparent backgrounds, distinct silhouettes and a small, solid-colour palette, and are checked at 24px, 60px and Kanidm launcher size on light and dark surfaces. `modules/Core_Modules/kanidm/assets/apps/` keeps byte-identical copies; active Kanidm launchers reference these Homepage originals directly. The Kanidm-only `assets/portal.svg` uses a matching blue house with an amber doorway for Home.

- `prowlarr.svg`: embeds the existing `prowlarr.png` tiger-in-a-box mark, matching the owner-provided reference without the wordmark (approved 2026-10-31). Keep the Kanidm copy identical.
