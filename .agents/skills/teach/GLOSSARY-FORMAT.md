# GLOSSARY.md Format

`GLOSSARY.md` is the teaching workspace's canonical language. Add a term only
after the user has demonstrated that they understand and can use it.

```md
# {Topic} Glossary

## Terms

**Canonical term**:
A tight one- or two-sentence definition.
_Avoid_: Ambiguous alias, misleading synonym
```

Choose one canonical term when several compete. Use already-established terms
inside new definitions, group natural clusters under headings, and state how
the workspace resolves ambiguous terminology. Revise definitions as the
learner's understanding deepens; do not preserve stale definitions.
