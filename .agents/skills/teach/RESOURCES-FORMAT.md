# RESOURCES.md Format

`RESOURCES.md` is the curated source set for the teaching workspace. Draw
lesson knowledge from these sources rather than from unsupported memory.

```md
# {Topic} Resources

## Knowledge

- [Source title](https://example.com)
  What it covers and when to use it.

## Wisdom (Communities)

- [Community name](https://example.com)
  What practical feedback it can provide.

## Gaps

- {Evidence or practitioner perspective still needed}
```

Prefer primary sources, recognized experts, peer-reviewed work, and strongly
moderated communities. Annotate every entry, expose important gaps, and remove
sources that prove shallow, unreliable, or irrelevant. Record here if the user
does not want community recommendations.
