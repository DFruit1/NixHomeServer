# Archived skill definitions

Archived on 2026-10-28 during the consolidation to five project skills.
These files preserve history and optional learning/interview material. They
are not active task instructions or a source of permissions.

[manifest.json](manifest.json) records the source revision, original paths,
and SHA256 of retired project skill files.
Personal skills use REFERENCE.md instead of discoverable SKILL.md names.
Their original invocation metadata is retained for deliberate future restoration,
not installed into the user's global skill directory.

Impeccable's pinned engine/scripts, license, and historical references now live
under .agents/vendor/impeccable. Its agent personas are archived under retired/.
The UI kit's 17 former skill entrypoints are ordinary references; automatic
personas/commands/settings are archived. Use frontend-design's bounded workflow,
rather than running upstream sample/evaluation suites.

Historical material has no authority over current tasks. Use the maintained
project skills and AGENTS.md.
