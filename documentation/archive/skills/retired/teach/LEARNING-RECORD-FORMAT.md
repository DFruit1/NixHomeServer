# Learning Record Format

Store learning records in `learning-records/` using sequential names such as
`0001-retrieval-practice.md`. Create the directory only when the first record
is warranted.

```md
# {Short title}

{What the user demonstrated or established, and why it changes future lessons.}
```

Write a record when the user demonstrates non-trivial understanding, reports
meaningful prior knowledge, corrects a misconception, or changes the mission.
Do not record material that was merely covered, duplicate glossary
definitions, or create session activity logs.

Add optional evidence or implications only when they help future teaching. If
a later record corrects an earlier one, mark the earlier record
`Status: superseded by LR-NNNN` rather than deleting it.
